# Contributing to chartcli

Thanks for your interest in chartcli. New here? Issues labeled
[good first issue](https://github.com/example/chartcli/labels/good%20first%20issue)
are a good place to start.

Everyone here follows the [Code of Conduct](CODE_OF_CONDUCT.md).

## Setting up

1. Install Go 1.22 or later.
2. Fork the repository and clone your fork.
3. Run `make` to build the tool.

## Testing

Run the tests with `make test`. A change that fixes a bug comes with a test
that fails without it.

## Pull requests

1. Open an issue to discuss the change, unless it's a small fix.
2. Push a branch to your fork and open a pull request against `main`.
3. Fill in the template, so a reviewer has what they need.

A maintainer reviews pull requests within a week. If you hear nothing by
then, comment on the pull request to bring it back up.
