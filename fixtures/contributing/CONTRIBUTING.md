# Contributing to chartcli

Pull requests are welcome, but read this first. Low-effort pull requests will be closed without comment.

## Setting up

You need Go 1.22. Simply clone the repository and run `make`.

## Testing

Run the tests with `make test`.

## Pull requests

1. You should open an issue before you start.
2. Then you push a branch and open a pull request.
3. As already stated, every change needs a test.
